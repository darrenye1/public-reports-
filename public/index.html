Featured Project

Automated Equity Research Pipeline

Inspiration. I built this project to automate financial data collection and valuation modeling — strengthening my ability to process raw market data, design repeatable models, and deliver institutional-style outputs without manual spreadsheet work.

The system pulls live data from Yahoo Finance, runs a blended valuation (Simon FCFE DCF, comparable multiples, and analyst consensus), filters outliers, and publishes sell-side-style PDF reports plus this interactive dashboard — synced weekly via GitHub and Vercel.
